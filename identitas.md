## Latihan Fork, Langkah demi Langkah

1. **Login** ke [github.com](https://github.com). Belum punya akun? Daftar dulu dengan email yang aktif.
2. **Buka repo soal** `perpusku-docs-raw` lewat tautan dari dosen.
3. Klik tombol **Fork** di pojok kanan atas halaman repo.
4. Pada halaman berikutnya, biarkan pengaturan bawaan, lalu klik **Create fork**.
5. **Periksa hasilnya.** Di kiri atas halaman, tulisannya harus `username-kamu/perpusku-docs-raw`, dan di bawahnya ada keterangan *forked from* ... Jika yang tampil masih nama dosen, kamu belum berada di repo milikmu.
6. **Salin URL** dari address bar browser (contoh: `https://github.com/username-kamu/perpusku-docs-raw`).
7. Buka file `identitas.md` di repo milikmu, klik **ikon pensil** (Edit this file) di kanan atas.
8. Isi tabel di atas, termasuk URL yang tadi kamu salin dan tanggal hari ini.
9. Klik **Commit changes...**, tulis pesan singkat (misalnya `Isi identitas`), lalu klik **Commit changes** sekali lagi. Perubahan baru tersimpan setelah langkah ini.
10. Kembali ke halaman utama repo milikmu dan pastikan isi `identitas.md` sudah terisi.
11. **Kirim URL repo** ke dosen sesuai instruksi di kelas.

## Checklist

- [ ] Sudah punya akun GitHub
- [ ] Fork berhasil (ada keterangan *forked from* di bawah nama repo)
- [ ] `identitas.md` sudah terisi dan sudah di-commit
- [ ] URL repo sudah dikirim ke dosen
- [ ] Repo bisa dibuka tanpa login (cek lewat jendela incognito)

## Kalau Ada Masalah

- **Tombol Fork tidak bisa diklik atau muncul pesan sudah pernah fork.** Kamu sudah punya fork. Klik foto profilmu di kanan atas, pilih **Your repositories**, lalu cari `perpusku-docs-raw`.
- **Ikon pensil tidak muncul.** Kemungkinan besar kamu sedang membuka repo dosen, bukan repomu. Periksa bahwa URL mengandung username-mu.
- **Sudah mengisi tabel tapi isinya tidak berubah.** Kamu belum menekan tombol **Commit changes** (langkah 9).
- **Tabel jadi berantakan.** Pastikan setiap baris tetap punya tiga tanda `|` (satu di kiri, satu di tengah, satu di kanan).
