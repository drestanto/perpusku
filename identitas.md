## Membuat Repo dari Template, Langkah demi Langkah

1. **Login** ke [github.com](https://github.com). Belum punya akun? Daftar dulu dengan email yang aktif.
2. **Buka repo template** `perpusku-docs-raw` lewat tautan dari dosen.
3. Klik tombol hijau **Use this template** di kanan atas halaman repo, lalu pilih **Create a new repository**.
4. Isi formulirnya:
   - **Owner**: akun GitHub-mu.
   - **Repository name**: `perpusku-docs-` diikuti NIM-mu (contoh: `perpusku-docs-2410123`).
   - **Visibility**: pilih **Private**.
   - Jangan centang *Include all branches*.

   Lalu klik **Create repository**.
5. **Periksa hasilnya.** Di kiri atas halaman, tulisannya harus `username-kamu/perpusku-docs-...`, ada label **Private** di sebelah nama repo, dan di bawahnya ada keterangan *generated from* repo template dosen. Jika tidak begitu, kamu belum berada di repo milikmu.
6. **Tambahkan dosen sebagai collaborator** supaya dosen bisa membuka repo privatmu: buka tab **Settings** → **Collaborators** (menu kiri) → **Add people** → ketik username GitHub dosen (diumumkan di kelas) → pilih akunnya → **Add**. Statusnya akan tampil *Pending invite* sampai dosen menerima undangan. Itu normal.
7. **Salin URL** repo-mu dari address bar browser (contoh: `https://github.com/username-kamu/perpusku-docs-2410123`).
8. Buka file `identitas.md` di repo milikmu, klik **ikon pensil** (Edit this file) di kanan atas.
9. Isi tabel di atas, termasuk URL yang tadi kamu salin dan tanggal hari ini.
10. Klik **Commit changes...**, tulis pesan singkat (misalnya `Isi identitas`), lalu klik **Commit changes** sekali lagi. Perubahan baru tersimpan setelah langkah ini.
11. Kembali ke halaman utama repo-mu dan pastikan isi `identitas.md` sudah terisi.
12. **Kirim URL repo** ke dosen sesuai instruksi di kelas.

## Checklist

- [ ] Sudah punya akun GitHub
- [ ] Repo dibuat dari template (ada keterangan *generated from* di bawah nama repo)
- [ ] Repo berstatus **Private**
- [ ] Dosen sudah ditambahkan sebagai collaborator
- [ ] `identitas.md` sudah terisi dan sudah di-commit
- [ ] URL repo sudah dikirim ke dosen

## Kalau Ada Masalah

- **Tombol Use this template tidak muncul.** Pastikan kamu sudah login dan sedang membuka repo template yang benar (tautan dari dosen).
- **Repo terlanjur dibuat sebagai Public.** Buka **Settings** → **General** → paling bawah bagian **Danger Zone** → **Change repository visibility** → **Make private**.
- **Ikon pensil tidak muncul.** Kemungkinan besar kamu sedang membuka repo template dosen, bukan repomu. Periksa bahwa URL mengandung username-mu.
- **Dosen tidak bisa membuka repomu.** Periksa lagi di **Settings** → **Collaborators** bahwa username dosen yang kamu ketik benar dan undangannya terkirim.
- **Sudah mengisi tabel tapi isinya tidak berubah.** Kamu belum menekan tombol **Commit changes** (langkah 10).
- **Tabel jadi berantakan.** Pastikan setiap baris tetap punya tiga tanda `|` (satu di kiri, satu di tengah, satu di kanan).
